# ✔ 데이터 분석이란

## 1️⃣ 데이터 분석과 데이터 과학

### 데이터 분석

- 유용한 정보를 발견하고 결론을 유추하거나, 의사 결정을 돕기 위해 데이터를 조사, 정제, 변환, 모델링하는 과정
- 올바른 의사 결정을 돕기 위한 **통찰**(insight)을 제공하는 데 초점을 맞춤
- 비즈니스 결정을 과학적으로 내리기 위한 도구로 사용됨

#### 통계적 관점에서의 데이터 분석

1. 기술 통계
   - Descriptive statistics
   - 관측이나 실험을 통해 수집한 데이터를 정량화하거나 요약하는 기법
   - ex) 평균, 최솟값, 최댓값

2. 탐색적 데이터 분석
   - Exploratory Data Analysis (EDA)
   - 데이터를 시각적으로 표현하여 주요 특징을 찾고 분석하는 방법

3. 가설 검정
   - Hypothesis testing
   - 주어진 데이터를 기반으로 특정 가정이 합당한지 평가하는 통계 방법

### 데이터 과학

- 데이터 과학은 통계학(statistics), 데이터 분석, 머신러닝(machine learning), 데이터 마이닝(data mining) 등을 아우르는 큰 개념
- 통찰에서 한 걸음 더 나아가 문제 해결을 위한 최선의 **솔루션**(solution)을 만드는 데 초점을 맞춤

## 2️⃣ 데이터 분석가

- 프로그래밍 기술을 갖추고 있고 통계학을 이해하면서 정보를 시각적으로 잘 표현할 수 있는 사람
- 데이터 분석가는 프로그래밍, 수학.통계, 도메인 지식(비즈니스 문제에 대한 전문 지식)이 모두 필요함

### 데이터 분석가의 작업 과정

#### 좁은 의미의 데이터 분석

- 기술 통계
- 탐색적 데이터 분석
- 가설 검정

#### 넓은 의미의 데이터 분석

- 데이터 수집
- 데이터 처리
- 데이터 정제
- 데이터 분석
- 모델링

## 3️⃣ 데이터 분석을 위한 도구

### 프로그래밍 언어: 파이썬과 R

- 데이터 분석에 많이 사용하는 프로그래밍 언어는 파이썬과 R 임
- 데이터가 데이터베이스 형태로 있다면, SQL(Structured Query Language)을 사용할 수 있음
  - 다만, SQL은 프로그래밍 언어가 아니고 데이터베이스를 다루기 위해 고안된 언어로, 시각화나 통계적인 분석을 수행하기는 어려움

#### 파이썬

- 귀도 반 로섬이 1991년에 만든 범용 프로그래밍 언어
- 과학 계산 분야에서 오래 사용해 왔고, 데이터 처리에 사용할 패키지가 풍부함
- 데이터 분석이나 머신러닝에서 표준 언어처럼 사용되고 있음

#### R

- 1995년에 통계 계산을 위해 개발된 언어로, 범용 프로그래밍 언어는 아님
- 아주 많은 통계 패키지와 훌륭한 그래프를 만들 수 있는 도구를 제공함
- 하지만, 데이터 수집, 전처리 등을 수행하기 까다롭고, 만들어진 모델을 제품 환경에 적용하기도 어려움
- 대신, 통계 관련 패키지는 파이썬보다 R이 더 많아서 아직도 학교나 기업에서 많이 사용됨

### 프로그래밍 환경: 구글 코랩

- 구글 코랩을 사용하면 내 컴퓨터에 직접 파이썬을 설치하지 않고 브라우저만으로 파이썬 프로그래밍을 할 수 있음
- 또, 아래의 파이썬 패키지를 모두 기본 제공하므로 별도로 설치하지 않아도 됨

### 파이썬 필수 패키지

#### 넘파이 (NumPy)

- numerical python의 줄임말
- 고성능 과학 계산과 다차원 배열(array)을 위한 파이썬 패키지
- 대부분의 파이썬 데이터 분석 패키지는 데이터를 다룰 때 넘파이 배열을 사용함

#### 판다스 (pandas)

- 마이크로소프트 Excel과 sheet처럼 숫자와 문자를 섞어서 표 형태로 저장할 수 있는 데이터프레임(DataFrame)을 사용함
- 편리한 데이터 처리와 분석 작업을 위해 많은 기능을 제공함
- 다양하고 미려한 그래프 출력 기능도 갖추고 있음
- 파이썬 데이터 분석에서 기본 자료 구조로 넘파이와 판다스를 자주 사용함

#### 맷플롯립 (matplotlib)

- 파이썬 데이터 시각화를 위한 기본 패키지
- 정적 또는 동적 그래프를 그릴 수 있고, 고품질의 매우 다양한 그래프를 제공함
- 파이썬의 다른 과학 패키지와 호환성이 높음
- 이외에도 파이썬에서는 시본(seaborn), 보케(bokeh) 같은 시각화 패키지를 많이 사용함

#### 사이파이 (SciPy)

- 넘파이를 기반으로 구축된 수학과 과학 계산 전문 패키지
- 미분, 적분, 확률, 선형대수, 최적화 등을 알고리즘으로 구현함

#### 사이킷런 (scikit-learn)

- 파이썬의 독보적인 머신러닝 패키지
- 파이썬 뿐만 아니라 전체 데이터 과학 분야에서 가장 널리 사용되는 머신러닝 패키지임
- 넘파이와 사이파이에 크게 의존함

## cf) 데이터 마이닝과 머신러닝

### 데이터 마이닝

- 데이터에서 패턴 혹은 지식을 추출하는 작업
- 패턴과 지식은 사람이 의사 결정을 내리기 위해 활용됨

### 머신러닝

- 데이터에서 자동으로 규칙을 학습하여 문제를 해결하려는 소프트웨어를 만드는 기술
- 딥러닝도 머신러닝 알고리즘의 한 종류 임
- 모델(model): 머신러닝으로 학습한 소프트웨어 객체

### 데이터 마이닝 vs 머신러닝

1. 규칙이나 패턴을 사용하는 주체
   - 데이터 마이닝: 사람
   - 머신러닝: 컴퓨터

2. 알고리즘
   - 데이터 마이닝: 규칙을 만드는 과정이 비교적 투명
   - 머신러닝: 블랙박스처럼 결정이 내려진 이유를 알기가 어려운 경우가 많음
