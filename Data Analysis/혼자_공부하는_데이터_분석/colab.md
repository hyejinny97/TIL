# ✔ 구글 코랩과 주피터 노트북

## 1️⃣ 구글 코랩

- 구글이 대화식 프로그래밍 환경인 주피터 노트북(jupyter notebook)을 커스터마이징한 것으로, 클라우드 기반 서비스 임
- 텍스트와 프로그램 코드를 자유롭게 작성할 수 있는 온라인 에디터 임
- 웹 브라우저에서 무료로 파이썬 코드를 작성, 실행, 저장할 수 있음
- 데이터 분석에 필요한 중요한 패키지를 모두 제공함

### 노트북 (notebook)

- 코랩 메모장이라고도 부름
- 작성한 코랩 파일을 의미함
- 노트북을 사용하면 코드를 설명하는 문서를 따로 만들지 않고, 코드와 텍스트를 함께 담을 수 있음
- 심지어, 코드의 실행 결과도 노트북과 함께 저장되므로, 다른 사람에게서 노트북을 받으면 코드를 실행할 필요 없이 실행 결과를 바로 확인할 수 있음

### 셀 (cell)

- 코드 또는 텍스트 덩어리
- 코랩에서 실행할 수 있는 최소 단위
- 셀 안에 있는 내용을 한 번에 실행하고 그 결과를 노트북에 나타냄
- 노트북은 보통 여러 개의 코드 셀과 텍스트 셀로 이루어짐

#### 텍스트 셀

- 텍스트 셀에는 HTML과 마크다운을 혼용해서 사용할 수 있음

#### 코드 셀

- 파이썬 코드를 입력하고 실행할 수 있는 셀
- 코드 셀은 마지막 라인의 실행 결과를 자동으로 셀 아래에 출력함

## 2️⃣ 코랩 노트북

- 코랩 노트북에 작성한 코드는 구글 클라우드에서 제공하는 가상 서버(런타임)에서 실행됨
- 가상 서버의 메모리는 약 12GB이고, 디스크 공간은 100GB 임
- 구글 계정만 있으면 무료로 가상 서버를 활용할 수 있음
- 단, 무료라 부담이 없는 한편 제한 사항이 있음
  - 코랩 노트북으로 동시에 사용할 수 있는 구글 클라우드의 가상 서버는 최대 다섯 개임
  - 한 개의 노트북을 12시간 이상 실행할 수 없음
- 노트북에서 일정 시간 아무 작업을 하지 않으면 자동으로 런타임과 연결이 끊어짐

### 새 노트북 만들기

- 노트북은 컴퓨터에 다운로드하거나 구글 드라이브에 저장할 수 있음
- 확장자가 `ipynb`인 주피터 노트북 파일이나 일반 파이썬 스크립트인 `py` 파일로 다운로드할 수 있음
