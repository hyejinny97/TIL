# ✔ 딥러닝 개발환경 구축하기

## 1️⃣ 딥러닝을 위한 준비물, 구글 코랩

- 코랩 (Colab): 2018년 구글이 공개한 주피터 노트북 서비스
- 주로 머신러닝과 데이터 과학 분야의 연구와 교육을 위한 플랫폼임
- 기본적으로 파이썬 언어를 지원하고, 데이터 분석과 딥러닝에 필요한 중요 패키지들을 무료로 제공함
- 파이썬 코드는 구글 클라우드에서 제공하는 무료 컴퓨팅 자원을 통해 실행되므로 내 컴퓨터에 파이썬이나 다른 라이브러리를 설치할 필요가 없음
- 주피터 노트북 (Jupyter notebook): 웹 기반의 인터랙티브 컴퓨팅 환경
  - 웹 브라우저로 코드를 작성하고 실행할 수 있는 도구
  - 노트북은 문서와 코드, 실행 결과를 모두 담은 파일임
  - 인터랙티브 환경: 독립적으로 하나의 코드 셀을 실행할 수 있음

## 2️⃣ 코랩의 화면 구성

- 코랩은 웹브라우저에서 텍스트와 프로그램 코드를 자유롭게 작성할 수 있는 온라인 에디터임
- 셀: 코랩에서 실행할 수 있는 최소 단위
- 노트북은 보통 여러 개의 코드 셀과 텍스트 셀로 이루어짐

### 텍스트 셀

- 텍스트 셀에는 HTML과 마크다운을 혼용해서 사용할 수 있음

### 코드 셀

- 코드 셀은 파이썬 코드를 입력하고 실행하는 셀임
- 마지막 라인의 실행 결과를 셀 아래에 자동으로 출력함

### 노트북

- 노트북은 구글 클라우드의 컴퓨터 엔진에 연결됨
- 구글 계정만 있다면 코랩 노트북을 사용해 무료로 가상 서버를 활용할 수 있음
- 제한 사항
  - 코랩 노트북으로 동시에 사용할 수 있는 구글 클라우드의 가상 서버는 최대 5개임
  - 한 노트북을 12시간 이상 실행할 수 없음

## 3️⃣ 코랩으로 실습 준비하기

### 텐서플로와 케라스

- 딥러닝 라이브러리는 머신러닝 라이브러리와 다르게 그래픽 처리 장치인 GPU를 사용하여 인공 신경망을 훈련함
  - GPU는 벡터와 행렬 연산에 매우 최적화되어 있기 때문에, 곱셈과 덧셈이 많이 수행되는 인공 신경망 훈련에 큰 도움이 됨

#### 텐서플로

- TensorFlow
- 2015년에 구글이 공개함
- 신경망 모델을 만들 수 있는 전문 라이브러리
- 핵심 연산은 C++과 GPU 프래그래밍을 위한 CUDA로 구현됨
  - CUDA: GPU를 사용해 여러 작업을 동시에 병렬 처리할 수 있도록 만들어 주는 프래그래밍 모델
- 고수준 API는 파이썬으로 제공됨
  - 파이썬 API 이외에 자바와 C++ API도 제공함
- 이제는 다양한 도구와 커뮤니티를 포괄하는 커다란 생태계로 성장함
  - TensorFlow.js: 자바스트립트 머신러닝 라이브러리
  - TensorFlow Lite: 모바일과 엣지 기기를 위한 머신러닝 라이브러리
  - TFX (TensorFlow Extended): 제품 환경의 머신러닝 파이프라인을 구성
  - 텐서 보드 (TensorBoard): 신경망 모델의 훈련 과정을 모니터링할 수 있는 시각화 도구

#### 케라스

- 텐서플로가 등장하기 전부터 씨아노(Theano) 딥러닝 라이브러리를 위한 고수준 파이썬 API를 제공해왔음
- 텐서플로가 출시된 후에는 발빠르게 텐서플로를 지원하며 텐서플로에서 가장 인기 있는 고수준 라이브러리가 됨
- 멀티 백엔드 정책: 케라스 라이브러리는 직접 GPU 연산을 수행하지 않고, GPU 연산을 수행하는 다른 라이브러리를 백엔드로 사용함
- 케라스 API만 익히면 다양한 딥러닝 라이브러리를 입맛대로 골라서 쓸 수 있도록 고수준 API를 제공함
- 텐서플로 2.0부터는 제 1의 API가 됨
- 케라스 2.4부터 여러 개의 딥러닝 프레임워크를 지원하는 멀티 백엔드 정책을 버리고 텐서플로 전용 API로 재단장함
- 케라스 3.0부터 다시 텐서플로, 파이토치, JAX를 백엔드로 사용할 수 있는 멀티 백엔드 고수준 API로 거듭남
- KerasNLP: 자연어 처리 전문 라이브러리
  - 2024년 10월, KerasHub로 라이브러리 이름이 변경됨
  - 하지만, 패키지 이름은 이전과 동일하게 사용할 수 있음
- KerasCV: 컴퓨터 비전 전문 라이브러리
