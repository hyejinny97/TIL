## 1️⃣ 타깃을 모르는 비지도 학습

- 비지도 학습: 타깃값이 없을 때 데이터에 있는 패턴을 찾거나 데이터 구조를 파악하는 머신러닝 방식
  - 타깃이 없기 때문에 알고리즘을 직접적으로 가르칠 수 없음
  - 대신, 알고리즘은 스스로 데이터가 어떻게 구성되어 있는지 분석함
  - ex) 군집, 차원 축소 등
- 군집은 대표적인 비지도 학습 중 하나임
  - 군집(clustering): 비슷한 샘플끼리 그룹을 모으는 작업
  - 클러스터(cluster): 군집 알고리즘에서 만든 그룹

## 2️⃣ 과일 사진 데이터 준비하기

#### 1. 과일 데이터를 불러오자

```py
import numpy as np

fruits = np.load('fruits_300.npy')
print(fruits.shape)  # (300, 100, 100)
```

- `load()`: npy 파일을 로드하는 넘파이 메서드
- shape 결과
  - 첫 번째 차원(300): 샘플의 개수
  - 두 번째 차원(100): 이미지 높이
  - 세 번째 차원(100): 이미지 너비
- 즉, 이미지 크기는 100 x 100이고, 각 픽셀은 넘파이 배열의 원소 하나에 대응함
- 300개 과일 중 처음 100개는 사과, 그다음 100개는 파인애플, 마지막 100개는 바나나임

## 3️⃣ 픽셀값 분석하기

#### 1. 과일 데이터를 사과, 파인애플, 바나나로 나눈 후, 1차원 배열로 펼치자

```py
apple = fruits[0:100].reshape(-1, 100*100)
pineapple = fruits[100:200].reshape(-1, 100*100)
banana = fruits[200:300].reshape(-1, 100*100)
```

## 4️⃣ 평균값과 가까운 사진 고르기

#### 1. 전체 과일에 사과 평균값으로 평균 절댓값 오차를 계산해보자

```py
abs_diff = np.abs(fruits - apple_mean)
print(abs_diff.shape)  # (300, 100, 100)

abs_mean = np.mean(abs_diff, axis=(1,2))
print(abs_mean.shape)  # (300,)
```

- `abs()`: 절댓값을 계산하는 함수
  - 배열을 입력하면 모든 원소의 절댓값을 계산하여 입력과 동일한 크기의 배열을 반환함

#### 2. 평균 절댓값 오차값이 가장 작은 순서대로 100개를 골라 그래프를 그려보자

```py
apple_index = np.argsort(abs_mean)[:100]
fig, axs = plt.subplots(10, 10, figsize=(10,10))
for i in range(10):
    for j in range(10):
        axs[i, j].imshow(fruits[apple_index[i*10 + j]], cmap='gray_r')
        axs[i, j].axis('off')
plt.show()
```

<img src='./apple_100.png' alt='사과 이미지 100개' width='250px' />

- `argsort()`: 작은 것에서 큰 순서대로 값을 나열하는 함수
- axis('off'): 좌표축을 그리지 않음
- 100개 전부 사과만 골라냈음
